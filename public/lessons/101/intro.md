## Why learn programming in the age of AI?
- It helps build up problem solving skills
- It helps you to be sure you covered all cases when writing down instructions for someone else on anything, such as chores, etc

## My Views on use of AI for this class
- I won’t be using it to demonstrate stuff in the class
- I don’t mind if you use it, but if you are wanting to learn there is a right way
- Many AI chatbots have a learning mode, or you can prompt it to ask you guiding questions, you can also use it to explain why things are done a certain way
- One usecase is often to see if you did something correctly. I’ll note that for a lot of our coursework, I will provide code to help you get started on problems which will include stuff to test it and print out whether or not it works for all the test cases
- The main thing to avoid is letting the AI do the work for you or reaching for it prematurely, spending some time trying to come up with a solution on your own will help build the connections in your brain
